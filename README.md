Entorno Seguro Python con Docker
Este proyecto surge como una solución a la necesidad crítica de desplegar aplicaciones de Python en entornos de producción de manera segura. En la actualidad, Python es el lenguaje más utilizado para desarrollo, pero un despliegue mal configurado puede exponer vulnerabilidades graves en los servidores.

¿Qué resuelve este proyecto?
Aislamiento total: Utiliza contenedores Docker para separar la aplicación del sistema operativo del servidor, minimizando el riesgo de ataques laterales.

Hardening de seguridad: Configuración optimizada para reducir la superficie de ataque y asegurar que los servicios críticos no queden expuestos.

Escalabilidad y Seguridad: Prepara el terreno para despliegues en la nube (Azure) con prácticas de DevSecOps integradas.
